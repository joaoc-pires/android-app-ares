# Ares

Ares is an RSS, Atom and JSON Feed reader for Android.

## Privacy

- No Google Play Services, Firebase or any other proprietary Google library.
- No analytics, no tracking, no ads.
- Works the same on devices without GMS, such as GrapheneOS.
- All connections use HTTPS only.

## Building

Requirements: JDK 21 and the Android SDK (platform 37).

```
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

### Open-source licences

The licences screen reads `app/src/main/res/raw/aboutlibraries.json`, generated by
[AboutLibraries](https://github.com/mikepenz/AboutLibraries) from the release dependencies.
After adding, removing or updating a dependency, regenerate it and commit the result:

```
./gradlew :app:exportLibraryDefinitions
```

The plugin is only applied when this task is requested, so normal builds stay free of its
configuration-time dependency resolution. The task works offline.
