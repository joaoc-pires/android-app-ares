# Ares

Ares is an RSS, Atom and JSON Feed reader for Android.

## Privacy

- No Google Play Services, Firebase or any other proprietary Google library.
- No analytics, no tracking, no ads.
- Works the same on devices without GMS, such as GrapheneOS.
- All connections use HTTPS only.

## Building

Requirements: JDK 21 and the Android SDK (platform 37).

```
./gradlew assembleDebug
./gradlew testDebugUnitTest
```
